# Storefront image assets

Copy the supplied project image assets into this folder before deployment:

- `grootman-emblem.jpg` — hero background
- `apparel-lineup.jpg` — apparel catalogue imagery
- `summer-campaign.jpg` — summer collection imagery
- `brand-mindset.jpg` — campaign section
- `brand-poster.jpg` — supporting brand poster

The complete starter ZIP created for this project contains these files under `public/images/`. This repository commit contains the app source; the image files still need to be added from that ZIP.
